# Ezomod website

Marketing site for Ezomod, an AI automation agency, live at https://www.ezomod.com. It is a fully static site built with Next.js and served by Cloudflare. There is no backend yet.

## Stack

| Concern | Choice |
| --- | --- |
| Framework | Next.js 15 (App Router), React 19, TypeScript strict |
| Output | `output: "export"`, a static site in `out/` |
| Hosting | Cloudflare (serves `out/`; reads `public/_redirects` and `public/_headers`) |
| Styling | Tailwind CSS 3.4 with brand tokens in `tailwind.config.ts` |
| Motion | `framer-motion` (movement and scale only, so text is never hidden before JavaScript runs) |
| Icons | `lucide-react` |
| Fonts | Inter and Sora through `next/font` (self-hosted) |

## Commands

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export to out/
node scripts/generate-icons.mjs   # regenerate favicon / app icons from public/logo.png
node scripts/check-pages.mjs      # after a build: meta, H1, JSON-LD, {{TODO}}, broken links and sitemap checks
```

## Structure

```
app/
  layout.tsx            Fonts, sitewide metadata (metadataBase = https://www.ezomod.com), Navbar/Footer
  page.tsx              Home page sections
  privacy/, terms/      Legal pages
  not-found.tsx         Custom 404 with links to main pages
  sitemap.ts            sitemap.xml, built from lib/routes.ts
  robots.ts             robots.txt, explicitly allows AI crawlers
  manifest.ts           Web app manifest
  favicon.ico, icon.png, apple-icon.png   Generated by scripts/generate-icons.mjs
components/             Page sections and UI (Hero, Services, Process, ContactSection, ...)
lib/
  site.ts               Canonical URL, brand name, contact email, absoluteUrl()
  seo.ts                pageMetadata(): title, description, canonical, OG and Twitter per page
  routes.ts             List of indexable routes (feeds the sitemap)
public/
  llms.txt              Plain-text summary of Ezomod for AI tools
  _redirects, _headers  Cloudflare redirect and header rules
  og-image.png          1200x630 share image
  logo.png, ezomod-logo.jpg, icon-192.png, icon-512.png
```

## SEO conventions

- Every page exports `metadata = pageMetadata({ title, description, path })`. Titles are 60 characters or fewer, descriptions 155 or fewer, and canonicals have no trailing slash.
- Add every new indexable page to `lib/routes.ts` so it appears in the sitemap.
- All SEO-critical text must be server-rendered. Animations may move or scale content, but must never start it at `opacity: 0`.
- Brand: write "Ezomod" in body text. "EZOMOD" is only for the wordmark and as `alternateName` in structured data.
- No pricing anywhere on the site.
- Structured data: build JSON-LD with `lib/schema.ts` and render it with `components/JsonLd.tsx` (server-side). All entities reference one Organization `@id`. Never put placeholder values in JSON-LD; omit the field instead.
- `{{TODO: ...}}` marks missing real content. `scripts/check-pages.mjs` fails while any remain; see `TODO_CONTENT.md`.

## Contact form and booking

- `app/contact/page.tsx`: Cal.com embed (`components/contact/CalEmbed.tsx`, lazy-loaded, shown only when `NEXT_PUBLIC_CAL_LINK` is set) plus the contact form (`components/contact/ContactForm.tsx`).
- `functions/api/contact.ts`: Cloudflare Pages Function handling `POST /api/contact`. It checks the honeypot, Turnstile and validation (`lib/contact.ts`, shared with the form), then sends the email through Resend.
- GA4 events: `booking_click` (any "Book a free 30-minute call" button, or calendar interaction) and `generate_lead` (form sent). See `lib/analytics.ts`.

## Environment variables

See `.env.example`. Set them in Cloudflare Pages (setup steps in `OFF_SITE_CHECKLIST.md`). `NEXT_PUBLIC_*` values are inlined at build time, so redeploy after changing them. Never commit real keys: the repository is public.

| Name | Used by | Purpose |
| --- | --- | --- |
| `NEXT_PUBLIC_CAL_LINK` | build | Cal.com booking link |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | build | Turnstile widget |
| `NEXT_PUBLIC_GA4_ID` | build | Google Analytics 4 (nothing loads if empty) |
| `NEXT_PUBLIC_GSC_VERIFICATION` | build | Search Console meta tag |
| `RESEND_API_KEY` | function (secret) | Resend API |
| `CONTACT_FROM_EMAIL` | function | Verified sender address |
| `CONTACT_TO_EMAIL` | function | Recipient (Ezomodalltech@ezomod.com) |
| `TURNSTILE_SECRET_KEY` | function (secret) | Turnstile verification |
